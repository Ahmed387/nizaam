# إعادة ضبط جدول عناصر فاتورة البيع

## التنفيذ
- تحويل جدول سطح المكتب إلى توزيع ثابت مع حد أدنى أوسع وتمرير أفقي محفوظ.
- إضافة نسب أعمدة صريحة تتكيّف مع ظهور عمود الربح أو اختفائه.
- تنظيم خلية المنتج: الاسم أولاً بسطرين كحد أقصى، ثم اللون والخصائص، ثم سعر الشراء ومؤقت الحجز.
- إبقاء أدوات الكمية والسعر والخصم والإجمالي والحذف وبطاقات الهاتف ومنطق الحجز كما هي.

## التحقق
- فحص TypeScript والبناء التلقائي.
- اختبار بصري لجدول سطح المكتب باسم طويل وخصائص متعددة إن أمكن دون إتمام أي فاتورة.
- التأكد من عدم وجود تعديلات على قاعدة البيانات أو الأرصدة أو الأرشيف.
